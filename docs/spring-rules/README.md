# Spring 2027 rules: images to share

Five ways of explaining the spring rule changes to students (the full plan is in
[`../proposals/spring-rules.md`](../proposals/spring-rules.md)). Each PNG is rendered at twice its size from the
HTML file of the same name.

| Image | Size | Best for |
|---|---|---|
| [Twelve tiles](spring-rules-tiles.png) | 1080×1350 (portrait) | A poster or handout: one tile per change |
| [Before and after](spring-rules-before-after.png) | 1600×900 (landscape) | A slide: each rule now and in spring, side by side |
| [The big three, then the rest](spring-rules-big-three.png) | 1080×1350 (portrait) | Explaining cell room, the Bell Tower and scoring with pictures |
| [Through a game](spring-rules-through-a-game.png) | 1600×900 (landscape) | A slide: the changes grouped as Dig, Build, Fight, The clock |
| [Dark square](spring-rules-square.png) | 1080×1080 | Discord or a social post |

To change one, edit its `.html` (plain HTML, open it in a browser to see it) and run `./render.sh` to remake
the PNGs. It needs Google Chrome or Chromium, and the network for the fonts.

The numbers come from the `spring-draft` rule set (`GameRules.SpringDraft`). When one changes there, change
it here too.
